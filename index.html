🌌 About Nova

Nova turns a simple login screen into a polished digital experience with atmospheric lighting, translucent surfaces, and subtle motion.

✨ Design philosophy: Minimal code. Maximum visual impact. Built as a lightweight starting point for UI/UX experiments and portfolio projects.

✨ Features

Designed to look futuristic while keeping the project easy to understand and customize.

🪟

Glassmorphism

Translucent panels, soft borders, and layered surfaces.

🌈

Neon Gradients

Purple and cyan accents create a vivid futuristic theme.

✨

Motion Effects

Smooth transitions and gentle floating animations.

🔐

Login UI

Email, password, remember-me, and sign-in interface concepts.

📱

Responsive Layout

Adapts to desktop, laptop, tablet, and mobile screens.

⚡

Framework-Free

Built with HTML and CSS without a frontend framework.
