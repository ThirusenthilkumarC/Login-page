## 🌌 About Nova

**Nova** is a futuristic authentication UI designed to deliver a clean and engaging login experience.

The interface combines:

* 🪟 Glassmorphism
* 🌈 Purple & cyan gradients
* ✨ Animated glow effects
* ⭐ Floating particles
* 🔲 Futuristic grid patterns
* 🎭 Smooth transitions
* 📱 Responsive layouts

The entire interface is created using **HTML5 and CSS3**, making it lightweight, fast and easy to customize.
