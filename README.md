## 🌠 Overview

**NOVA** is a futuristic login page designed to transform a traditional authentication screen into an immersive digital experience.

The project combines a premium dark interface, translucent glass panels, neon gradients, ambient lighting, and interactive form controls.

Built using **HTML5, CSS3, and vanilla JavaScript**, NOVA delivers a responsive frontend without requiring a framework or complex installation.

> ✨ Minimal code. Maximum visual impact.

## 🚀 Getting Started

### Prerequisites

You only need:

* A modern web browser
* A text editor such as Visual Studio Code
* An internet connection for external README graphics

### 1. Clone the Repository

Replace the repository URL if your GitHub repository has a different name.

```bash
git clone https://github.com/ThirusenthilkumarC/Nova-Login.git
```

### 2. Open the Project Folder

```bash
cd Nova-Login
```

### 3. Launch the Website

Open `index.html` directly in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

### 4. Explore NOVA

* Enter an email address.
* Enter a password with at least six characters.
* Test the Show / Hide password control.
* Toggle Remember Me.
* Test form validation.
* Try the Google and GitHub buttons.
* Explore the responsive design on different screen sizes.

> **Note:** Social login, password recovery, and account creation display demonstration messages. They are not connected to a real authentication service.

## 🔍 How It Works

### Email Validation

JavaScript checks whether the email field contains a valid email format before allowing the form demonstration to continue.

### Password Validation

The password field requires at least six characters for the demo form to proceed.

### Show / Hide Password

The visibility control switches the password field between masked and readable text.

### Notification System

A reusable notification component displays feedback when users submit the form or select unsupported authentication actions.

### Animated Background

An HTML Canvas animation renders lightweight floating particles. CSS provides the grid, gradient lighting, and glass effects.

### Responsive Layout

CSS media queries adapt the introduction section and login card to smaller screens.

## 🔐 Security Notes

NOVA is currently a **frontend UI demonstration**, not a complete authentication system.

* No real user account is created.
* No password is sent to a backend.
* Google and GitHub OAuth are not configured.
* Forgot Password does not send reset emails.
* Remember Me is a visual checkbox and does not create a persistent session.
* No database is connected.
* Client-side validation alone does not provide authentication security.

For production use, integrate a secure backend, password hashing, server-side validation, appropriate session management, HTTPS, and a database. Use established OAuth flows for third-party sign-in.
