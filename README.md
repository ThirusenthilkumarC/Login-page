🌌 Nova — Modern Login Page

A modern, futuristic and responsive Login Page UI built using pure HTML and CSS.

Nova features a clean glassmorphism interface with animated background effects, gradient buttons, floating particles and responsive design.

✨ Features

- 🌌 Modern futuristic UI
- 🪟 Glassmorphism login card
- 🎨 Purple & cyan gradient theme
- ✨ Animated background glow
- ⭐ Floating particle animation
- 🔲 Subtle grid background
- 🔐 Email & password input fields
- ☑️ Remember me option
- 🔗 Forgot password link
- 🚀 Gradient animated Sign In button
- 🔵 Google & GitHub login buttons
- 👤 Create account option
- 📱 Fully responsive design
- ⚡ Pure HTML & CSS
- 🎭 Smooth hover and entrance animations

🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- CSS Glassmorphism
- Responsive Web Design
